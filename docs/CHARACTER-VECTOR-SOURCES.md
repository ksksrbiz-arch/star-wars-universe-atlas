# Character vector-art source review

Checked November9,2026. The requested direction is character artwork itself, presented clearly against the interface. Foil, trading-card frames and simulated rarity are outside this direction.

No consistent, detailed, full-body SVG source covering all964 current Databank characters was verified. A real SVG is resolution independent; wrapping an existing photo in `<svg><image>` does not add detail or turn it into vector artwork. Current source portraits must remain honestly identified as raster fallback wherever a genuine vector/cutout is unavailable.

The near-term image-first implementation can use reviewed transparent character artwork from an original/official provider, with the existing Databank portrait as fallback. TransparentPNG/WebP can look clean and sharp at appropriate sizes without pretending to be SVG. Maintain source credit, era/costume notes where known, original dimensions, alpha validation and stable entity IDs. A longer-term native-vector set requires an actual creator's coherent collection or commissioned artwork; it should not be advertised as already covering the full Databank.

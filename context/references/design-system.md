# Design system

Initial visual direction: dark navy space, warm pale text, cyan navigation, amber selection, and restrained world-specific color. Legible ordinary text carries all meaningful information. Decorative lettering cannot replace labels.

Keep the galaxy as the main visual surface. Desktop context belongs beside the map; phone context must preserve a usable view and touch controls. Use readable contrast, visible keyboard focus, and generous touch targets. Avoid effects that hide Back, Skip, destination labels, or source caveats.

This is a starting contract; actual styles and measured contrast remain subject to integrated review.

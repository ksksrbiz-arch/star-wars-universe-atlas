# Performance and verification

Status: targets and checklist, not completed benchmark evidence.

Validate build/types using the actual commands in the installed project configuration. Check destination selection, Skip, Cancel/Back, rapid replacement navigation, reduced motion, keyboard access, resize, mobile framing, and WebGL fallback. Confirm minimap and main-map orientation agree.

Collect actual browser/device/viewport and build revision with results. Measure frame times on representative hardware before promising smoothness or a frame-rate target. A successful build does not prove mobile interaction quality; an HTTP image response does not prove visual correctness.

Record failures and untested paths candidly. Repeat checks only when changes or unresolved failures justify it.

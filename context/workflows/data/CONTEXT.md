# Data workflow

Status: current contract for the deployed preview. `npm run check:icm` verifies the named `context/` paths, npm scripts and relative links.

## Input

Read [canon and sources](../../references/canon-and-sources.md) and [map and motion](../../references/map-and-motion.md) first. Then load only the modules the change touches; for a batch-level change also read the matching entry in [release history](../../../evidence/release-history.md).

| Load | Do not load |
|---|---|
| Map worlds and grids: [data.ts](../../../src/data.ts), [journeyWorlds.ts](../../../src/journeyWorlds.ts), [mappedWorldsExpansion.ts](../../../src/mappedWorldsExpansion.ts), [referencePlacements.ts](../../../src/referencePlacements.ts) | Rendering components and CSS |
| Catalog records: [catalog.ts](../../../src/catalog.ts) and generated [catalog.generated.json](../../../src/catalog.generated.json), regenerated by [build-catalog.py](../../../scripts/build-catalog.py) from the matching `docs/*-source.json` | Other series' episode prose |
| Story/location joins: [connections.ts](../../../src/connections.ts) plus only the touched per-series `connections*.ts` module (for example [connectionsRebelsSeason4.ts](../../../src/connectionsRebelsSeason4.ts)) and [locations.ts](../../../src/locations.ts) | Unrelated per-series connection modules |
| Viewing sequences and order: [chronology.ts](../../../src/chronology.ts) and [sequence-extension-baselines.json](../../../db/sequence-extension-baselines.json) | Map camera and warp code |
| Published database content: [001_atlas.sql](../../../db/001_atlas.sql) and `db/publications/` (changes need a reviewed migration and new publication version) | Cloudflare deploy scripts unless releasing |
| The batch's source review under `evidence/` and its `docs/*-source.json` | All other historical research |

## Tests

Deterministic, non-browser checks (run those matching the touched module): `npm run test:catalog`, `npm run test:connections`, `npm run test:chronology`, `npm run test:journey-data`, `npm run test:reference-data`, `npm run test:world-stories`, `npm run test:destination-links`, `npm run test:reconciled-worlds`, `npm run test:publication`, plus the batch's own script such as `npm run test:bad-batch-season-3` or `npm run test:rebels-season-4`. When a count changes, update the pinned counts in these tests and in [context/CONTEXT.md](../../CONTEXT.md).

## Process

Agent judgment resolves identity and evidence. Deterministic checks verify IDs, required fields, finite coordinates, and projection bounds. Keep published grid distinct from schematic x/y and explain parent-system joins.

## Output

Reviewable data diff, source links, unresolved claims, and relevant validation results.

## Completion

Changed claims have evidence or explicit uncertainty; IDs are unique and existing sequence ID prefixes are preserved; existing consumers still compile (`npm run build`); no unplaced world silently renders at origin.

## Stop conditions

Do not publish an unsupported identity join or precise position. Record the missing source and continue independent records. Do not request approval for routine reversible validation.
